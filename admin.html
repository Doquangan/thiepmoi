Deploy Lên Vercel

Đường link truy cập trang Admin trên Vercel của bạn sẽ là: https://tên-miền-của-bạn.vercel.app/admin-server

Cách triển khai nhanh:

  1. Đẩy dự án lên GitHub của bạn (git push).
  2. Đăng nhập Vercel.com, chọn Add New → Project.
  3. Chọn repository và bấm Deploy.
  4. Sau khi deploy xong, truy cập /admin-server để nhập mã PIN và quản lý thiệp mời!
